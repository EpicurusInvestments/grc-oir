Introducción
Este documento especifica el modelo de datos del Sistema GRC-OIR v2. Organizado en 5 fases de implementación. Cada entidad incluye campos con tipo de dato, tipo de origen, restricciones, fórmulas de cálculo, catálogos relacionados y reglas de validación.
Convenciones
🔑 PK — Llave primaria. Identificador único, generado automáticamente.
🔗 FK — Llave foránea. Referencia a la PK de otra entidad.
NOT NULL — Campo obligatorio. FK NULL — Referencia opcional.
Tipos de origen de campos
Manual — Capturado por el usuario.
Calculado — Generado automáticamente mediante una fórmula. No editable directamente.
Derivado — Valor que se obtiene de otro campo o entidad relacionada.
Auto — Clave o timestamp generada por el sistema.
Catálogo — Valor que se selecciona de un catálogo existente.
Booleano — Campo de sí/no, usado principalmente para filtros.
Relación — Llave foránea que establece la relación con otra entidad.
Cat/Manual — Se sugiere del catálogo pero permite captura manual si el valor no existe.
Actores del sistema
Internos (operan el sistema): Ventas, Facturación, Tesorería, CxC, CxP, Dirección/Finanzas, Nóminas.
Externos (no acceden al sistema): Clientes, Agencias, Afiliados. Toda información de externos entra por captura manual o carga de archivo.

FASE 1 — Órdenes de Transmisión
Flujo operativo central. El anunciante envía una orden (OrdenCliente) con los datos generales de la campaña. De ahí se derivan las órdenes internas (OrdenEstacion), siempre ligadas a la original. Asignar una orden interna significa programarla: estación, contrato, categoría, horarios, spots y precio. Después de la transmisión llega el reporte de lo realmente ejecutado (Verificación). Si no coincide, se editan las órdenes internas para reflejar la realidad. Solo cuando están ajustadas se cierran (orden_cerrada) — y solo entonces Facturación puede jalar la información.
OrdenCliente
Orden de transmisión recibida del anunciante (cliente comercial) o su agencia. Es el documento de referencia para facturación y cobro. Contiene los datos comerciales, la programación de transmisión y tres estados independientes: orden, pago a afiliado y pago a agencia. Al cerrarse (estatus_orden = orden_cerrada) habilita la facturación.
